# 🍥 Página Naruto

Página interativa em HTML, CSS e JavaScript puro dedicada ao Time 7 de *Naruto*: Naruto Uzumaki, Sasuke Uchiha, Sakura Haruno e Kakashi Hatake. Ao clicar em cada personagem, o conteúdo da página é atualizado dinamicamente com informações e imagem correspondentes, junto com uma troca de cor temática.

🔗 Repositório: [DevAlexandreSantos/Pagina-naruto](https://github.com/DevAlexandreSantos/Pagina-naruto)

## ✨ Funcionalidades

- Exibição do Time 7 com imagem em destaque
- Menu com os quatro personagens principais
- Ao clicar em um personagem: exibe informações específicas e troca a cor de destaque da página
- Botão para voltar à visualização do Time 7 completo

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout
- **JavaScript** — interatividade (troca de personagem e de cor)
- Fonte **Poppins** (Google Fonts)

## 📁 Estrutura do projeto

```
Pagina-naruto/
├── img/            # Imagens dos personagens e logo
├── index.html      # Estrutura principal da página
├── styles.css       # Estilos da página
└── scripts.js       # Lógica de interação (troca de personagem/cor)
```

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/DevAlexandreSantos/Pagina-naruto.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Pagina-naruto
   ```
3. Abra o arquivo `index.html` no navegador (ou use uma extensão como Live Server no VS Code).
